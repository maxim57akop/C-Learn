# C Programming — Learning Journey

My journey learning C as a foundation for Embedded Systems and Drone Development.

## Completed Topics

### 1. Introduction to C ✅
- Understanding how C programs work.
- Compiling and running programs using GCC and Clang.
- Understanding `main()`, `printf()`, and `return 0`.
- Basic syntax, header files, and comments.

### 2. Variables and Data Types ✅
- Working with `int`, `char`, `float`, and `double`.
- Using `short`, `long`, `signed`, and `unsigned`.
- Declaring and initializing variables.
- Understanding `const`, `sizeof`, and data type ranges.
- Reading user input with `scanf()`.
- Understanding unsigned integer overflow.

### 3. Operators ✅
- Arithmetic, comparison, and logical operators.
- Increment and decrement operators (`++`, `--`).
- Assignment operators (`+=`, `-=`, `*=`, `/=`, `%=`).
- Operator precedence and type casting.
- Understanding integer and floating-point division.

### 4. Conditional Statements ✅
- Working with `if`, `else if`, and `else`.
- Writing nested conditions.
- Using `switch`, `case`, `break`, and `default`.
- Understanding the ternary operator (`?:`).
- Practice: Battery level monitoring.

### 5. Loops ✅
- Working with `for`, `while`, and `do while`.
- Controlling loops using `break` and `continue`.
- Writing nested loops.
- Performing calculations and accumulating values in loops.
- Practice: Drone battery discharge simulation.

## Goal
Become a Junior C/C++ Embedded Developer, focusing on STM32, FreeRTOS, PX4, and MAVLink.
